# Contributing and Contributor Agreement

XRENGINE welcomes contributions, but it also offers commercial licenses.
Contributors therefore must grant the Project owner enough rights to release
their work under both the Community Source License and commercial terms.

Do not submit confidential code, third-party material without a compatible
license, credentials, personal data, or anything You cannot license.

## Contribution Process

1. Open or reference an issue or discussion for substantial work.
2. Follow `AGENTS.md` and nearby code and test patterns.
3. Run the narrowest useful validation.
4. Identify third-party, generated, and materially AI-assisted work.
5. Accept the Contributor Agreement below before merge.

The pull request records an individual contributor’s acceptance. The Project
owner separately retains any private organizational records. A public
legal-name or signature registry is not required.

## How Individuals Accept

Submit the pull request through your GitHub account and check the Contributor
Agreement acceptance box in the pull request template:

> By submitting this pull request, I accept the XRENGINE Contributor Agreement
> for Contributions made through this GitHub account and confirm that I have
> authority to grant these rights.

Your GitHub account and affirmative acceptance form the public acceptance
record. You do not need to publish your legal name in the pull request. If
additional identity or authority verification is reasonably necessary, it
will be requested privately.
