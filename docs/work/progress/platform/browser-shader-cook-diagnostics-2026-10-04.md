# Browser shader cook compiler diagnostics

ShaderCooker preserves Slang compiler failures as `ShaderCompilationException` diagnostics. Each compiler location inside the admitted source root is reported as a logical relative path with the compiler's line and column. A location outside that root has no published path or coordinates. When no compiler error is recognized, bounded fallback output keeps separable failure text. It removes quoted absolute paths and unquoted Windows-drive, UNC or Unix-root path-bearing text through the end of a line unless a clear compiler reason separator allows the suffix to be kept. It does not invent coordinates. This also keeps an unrecognized fatal line that follows a recognized warning. The recipe's material, pass, source and target remain attached to direct Slang compilation, generated material planning and compilation, and isolated native-vertex programs. Native compute and auxiliary compiler failures identify their own pass, entry and compiler source alongside the authored material source. Native-vertex compiler coordinates refer to the generated Slang function; the recipe context identifies the authored material JSON without assigning those generated coordinates to it.

An isolated Release build of the small ShaderCooker project passed with zero warnings and errors. A broken schema-3 present shader reported `AdvancedPresent.slang:27:20` and `undefined identifier 'missingValue'` with material and pass; its unchanged valid recipe packaged one artifact. A broken native-vertex body reported `NativeVertexFunction.slang:4:15` and the same compiler reason with its material, pass and authored material source; its unchanged valid recipe packaged eight artifacts. Unsupported authored lit feature fixtures in both ordinary and native-vertex material recipes reported their material, pass, authored source and unsupported base-color reason. A narrow parser witness verified fallback reasons for fatal-error and path-with-parentheses formats, unquoted paths with spaces on Windows and Unix, and a warning followed by an unrecognized fatal line, while omitting absolute paths and coordinates. Neither failed compiler cook published a manifest. The valid native-vertex manifest matched the previous fixture byte for byte. Evidence is in the ignored `Build/_AgentValidation/20261001-225000-lit-surface/scratch/diagnostic-cook/` run directory.
