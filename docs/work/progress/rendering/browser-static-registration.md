# Browser static registration and portable IDs

The browser profile has an explicit registration manifest at `XREngine.Browser/browser-registration-manifest.json`. `Tools/Generate-BrowserRegistrations.py` accepts only its reviewed type/signature allow-list and writes `XREngine.Browser/BrowserStaticRegistrations.g.cs` deterministically. Regenerate the checked-in source with `python3 Tools/Generate-BrowserRegistrations.py`; `--check` compares without writing. The generator does not inspect source files or assemblies, and the runtime never scans assemblies for browser factories.

The versioned `xre.browser.v1.*` IDs cover the browser scene's mesh, spin, and scene-boot components; the TRS transform; mesh, RGBA8 texture, unlit material, and scene-snapshot resource types; scene JSON serializer; and the WebGPU backend module. IDs are exact, case-sensitive and reject unknown values. They identify browser portable-profile content; they do not replace engine type names or IDs in desktop cooked assets. Any change to an ID or payload representation requires an explicit version/schema decision, preserving existing IDs for already-cooked browser content.

The generated table uses `SceneNode.AddComponent(Func<T>)`, `TransformFactoryRegistry.Register`/`TryCreate`, concrete validated browser resource constructors and `RendererBackendCatalog.Register` through the browser composition root. The WebGPU module retains its existing `RendererBackendId.WebGPU` and `RuntimeGraphicsApiKind.WebGPU`. `BrowserSceneSnapshot` uses a source-generated `BrowserSceneJsonContext` for the exact wire DTO graph while retaining the bounded validation and unknown-field rejection.

`BrowserStaticRegistrations.SerializeScene(SceneJsonId, snapshot)` produces a `xre.browser.scene.v1` cooked envelope. It embeds the existing snapshot JSON as an object and carries the exact serializer, snapshot, mesh-component, transform, mesh, material and texture IDs. Import checks every identity before constructing resources; unknown, duplicate and missing fields are rejected. `DeserializeScene` also accepts the previous flat snapshot version `1`, so existing exported scenes continue to import. The `BrowserSceneExports.EncodeSceneEnvelope(json)` host export converts supported flat or enveloped JSON without stopping a running scene. The typed envelope represents the static mesh/material/instance subset only; it does not imply a general desktop cooked-asset loader.

Source implementation is in place. Browser publish, source-generation diagnostics, and live round trips have not been validated in this pass.
